# Phrolova Chibi — powered by Amazon River

Gerar o APK: GitHub > Actions > "Build APK" (ou Android Studio > Build APK).

Phrolova na tela (botão "Adicionar à tela"): exige "Exibir sobre outros apps".
Teclado e WhatsApp (botão "Ativar WhatsApp"): ative "Phrolova Chibi" em Acessibilidade.
Android 13+ (APK instalado fora da loja): Info do app > menu ⋮ > "Permitir configurações restritas".
O serviço de acessibilidade só lê POSIÇÕES (janela do teclado, botão de chamada e campo de mensagem do WhatsApp). Não lê mensagens.
